## ✨ Overview

A premium, responsive tourism website for **Panda Tours & Travels**, focused on curated Kashmir journeys. The experience includes destination discovery, packages, seasonal travel inspiration, guest gallery, testimonials, FAQs, direct WhatsApp enquiries, trip planning and mobile navigation.

## 🚀 Live Demo

**Live website:** https://satitech-official.github.io/panda-tour-website/

## 🧩 Highlights

- Premium responsive Kashmir travel design
- Srinagar, Gulmarg, Pahalgam, Sonamarg and Gurez destination explorer
- Curated Kashmir packages and travel styles
- Guest arrival photo gallery with lightbox
- Seasonal Kashmir experience sections
- Testimonials and FAQs
- Trip planner connected to WhatsApp
- Mobile-friendly navigation and interactions
- SEO metadata and social preview image
- Automated GitHub Pages deployment on every push to `main`

## 🛠️ Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS / custom responsive styling
- GitHub Actions
- GitHub Pages

## 💻 Local Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
